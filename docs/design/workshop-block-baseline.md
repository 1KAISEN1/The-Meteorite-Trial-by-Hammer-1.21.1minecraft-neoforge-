# 锻造工坊功能方块基线

状态：已确认的功能范围；本轮只注册和提供测试占位贴图，不实现具体工艺逻辑。

## 手工加工站

| 方块 | 将来职责 | 水力替代 | 当前状态 |
|---|---|---|---|
| Forge Hearth | 加热工件；供手锻、锻焊前加热使用 | Water Bellows 只稳定鼓风，不替代玩家控制 | 测试占位 |
| Smithing Anvil | 自由锤击、成形、局部形变 | Trip Hammer 只能重复下锤 | 测试占位 |
| Quenching Basin | 水、油等淬冷介质；承接淬火 | 无 | 测试占位 |
| Heat Treatment Furnace | 退火、回火、正火等受控加热 | Water Bellows 可作为后续热源辅助 | 测试占位 |
| Grinding Wheel | 粗磨、开刃、磨削至内部材料层 | 后续可由水力轴驱动，但不自动决定磨削位置 | 测试占位 |
| Hafting Bench | 木柄削制、钻孔、装柄、铆接式装配 | 无 | 测试占位 |

## 水力辅助工坊

| 方块 | 将来职责 | 自由度边界 | 当前状态 |
|---|---|---|---|
| Water Wheel | 从流水取得旋转动力 | 不做通用工业能源网 | 测试占位 |
| Drive Shaft | 在有限工坊范围内传递水力 | 不模拟无限距离传动 | 测试占位 |
| Water Bellows | 为炉体提供更稳定、强劲的鼓风 | 不替代温度和工艺选择 | 测试占位 |
| Trip Hammer | 对已定位的规则坯料进行重复锤击 | 不可替代手锤的局部、变角度成形 | 测试占位 |

## 明确不在本轮实现的内容

- 温度、应力、碳量、合金、共鸣与品质公式。
- 方块实体、GUI、配方、传动网络、自动化逻辑和物品交互。
- 最终模型、碰撞箱、朝向与正式贴图。

## 自由度原则

任何自动装置只执行重复、可预期的动作。材料选择、坯料布置、折叠、锻焊、扭转区段、局部形状、热处理时机和磨削深度仍由玩家决定。
