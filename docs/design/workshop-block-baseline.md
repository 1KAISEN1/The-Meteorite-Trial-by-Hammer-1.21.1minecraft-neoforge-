# 锻造工坊功能方块基线

状态：已确认的功能范围；本轮只注册和提供测试占位贴图，不实现具体工艺逻辑。

## 手工加工站

| 方块 | 将来职责 | 当前状态 |
|---|---|---|---|
| Forge Hearth | 加热工件；供手锻、锻焊前加热使用 | 测试占位 |
| Smithing Anvil | 自由锤击、成形、局部形变 | 测试占位 |
| Quenching Basin | 水、油等淬冷介质；承接淬火 | 测试占位 |
| Heat Treatment Furnace | 退火、回火、正火等受控加热 | 测试占位 |
| Grinding Wheel | 粗磨、开刃、磨削至内部材料层 | 测试占位 |
| Hafting Bench | 木柄削制、钻孔、装柄、铆接式装配 | 测试占位 |

## 冶金与复合坯料

| 方块 | 将来职责 | 当前状态 |
|---|---|---|
| Bloomery Furnace | 块炼铁及含渣铁块的来源路线 | 测试占位 |
| Finery Hearth | 高碳生铁的脱碳/精炼路线 | 测试占位 |
| Carburizing Chest | 木炭环境下的渗碳与表面碳量调整 | 测试占位 |
| Cofusion Furnace | 熟铁与生铁结合的灌钢候选工艺 | 测试占位 |
| Twisting Fixture | 夹持规则长条复合坯，执行受限轴向扭转 | 测试占位 |
| Casting Mold Table | 铸件模具准备；不替代手工精修与锻造 | 测试占位 |

## 明确不在本轮实现的内容

- 温度、应力、碳量、合金、共鸣与品质公式。
- 方块实体、GUI、配方、自动化逻辑和物品交互。
- 最终模型、碰撞箱、朝向与正式贴图。

## 自由度原则

任何自动装置只执行重复、可预期的动作。材料选择、坯料布置、折叠、锻焊、扭转区段、局部形状、热处理时机和磨削深度仍由玩家决定。
